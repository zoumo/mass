# MASS Runtime 架构设计

本文描述已批准的 Runtime 架构方向。当前 Rust 产品已实现本地 Codex 与共享适配栈的 Codex Remote；准确字段、状态和最小范围以[当前合同](README.md)为准。候选、建议和待定项仍属未来范围。生产 Claude/ACP、在线登记管理及 Remote 跨连接恢复尚未交付。

架构不绑定实现语言、框架或源码布局。更换实现语言时，应保留角色责任、数据含义、状态转换、消息与持久化语义，以及并发和失败规则。

## 1. 已基本认可的原则

- 系统提供 Runtime 类型，用户注册命名配置实例。配置采用 `name`、`type`、`config`，Session 用 `runtimeName` 引用实例，展示也只使用 `name`。
- `type` 是唯一的实现选择。类型规定 `config` 的字段和校验，不再增加顶层 `protocol`、`provider`、`transport`、`launch` 或重复参数对象。
- 本地实例首次使用时激活。一个本地 Codex 实例拥有一个 app-server，其多个 Session 共享该服务。不同实例即使配置相同也不自动共享。
- 实例身份不依赖进程。进程退出或重建不改变实例和 Session 的持久归属。
- sessionId 由底层 Agent 创建并返回，MASS 原样保存并作为统一会话 ID 使用，不另分配第二个会话 ID。用户命名的 sessionName 与它独立；外围不解析 ID 的原生格式。
- 远程实例只拥有自己的连接和绑定会话，不拥有远端共享服务。不同名称不保证远端资源隔离。
- 原生协议知识集中在类型适配，外围只使用 MASS 命令、事实、错误和恢复合同。
- 采用终态接口、外部协议和持久化格式，不提供旧格式读取、兼容输出、双写或迁移，不删改现有运行数据。

首版已确定的类型、默认值、入口和生命周期以执行约定及当前合同为准。下文超出首版的建议不表示已实现或已批准新增范围。

## 2. 对象与架构职责

Runtime 是 MASS 控制 Agent 运行的核心合同，规定命令、结果、能力、事件、失败和资源所有权。

| 对象 | 含义 |
|---|---|
| Runtime 类型 | 系统提供的运行适配能力，决定配置规则和运行行为，用户不能上传实现 |
| Runtime 实例 | 用户登记的命名配置，持久存在，注册不启动进程 |
| 运行资源 | 实例使用的进程或服务连接，可以退出和重建 |
| Session | 以 Agent 返回的 sessionId 标识、具有用户命名 sessionName、配置和历史的会话，归档后仍存在 |
| Attachment | Session 与某次具体运行连接的绑定，恢复后产生新绑定，旧命令不能转向它 |

`codex1` 和 `codex2` 若都是本地类型，注册时都没有 app-server，分别首次使用后有两个。`codex1` 的多个 Session 共享它的服务，各自保持独立绑定。停止进程不等于删除实例，恢复进程也不等于恢复 Session。

| 架构角色 | 责任 |
|---|---|
| Runtime 核心合同 | 定义生命周期、命令、结果、领域错误、能力和统一事实，不依赖具体 Agent |
| 类型适配 | 解释类型配置，转换原生命令、事实和错误，维护原生控制状态，验证恢复信息并管理己方资源 |
| 实例管理 | 登记和查询实例，调度类型校验，协调配置版本、引用和变更 |
| Session 管理 | 预留用户名称，保存 Agent 返回的 sessionId 及实例归属，协调持久记录与具体 Attachment |
| 事件提交与分发 | 分配序号和时间，提交完整事实，维护快照，向实时订阅和事件处理器分发 |
| 持久化 | 原子保存元信息，保存顺序历史和不透明证据，执行通用结构与序号校验 |
| 外部协议 | 校验请求，将 MASS 结果和领域错误编码为外部响应，提供实时订阅 |
| 系统组装 | 提供系统支持的类型并注入实例依赖，协调退出 |

系统登记类型与用户登记实例分开。类型登记确定可用适配能力；用户只能选择已提供类型。无需动态插件加载。具体原生知识不能通过事件、错误或恢复校验绕回通用角色。

## 3. 实例字段

### 3.1 通用配置

| 字段 | 含义 | 必填与默认候选 |
|---|---|---|
| `name` | 字符串，实例唯一的展示和引用名称 | 必填，无默认；建议不可变，限制长度和非法字符 |
| `type` | 系统受控类型名，唯一的实现选择 | 必填，无默认；准确枚举待定 |
| `config` | 所选类型规定的参数对象 | 按类型校验，是否可为空由类型说明 |
| `enabled` | 是否允许实例接受新的使用 | 候选可选字段，建议默认启用；禁用效果仍待确认 |

工作目录、输入内容、Session 身份和恢复绑定不属于实例注册配置。Session 通过 `runtimeName` 引用 `name`，再提供自身操作参数。描述底层 Agent 的 `agentType` 未确认，不列为必要字段；若保留，只能展示，不能影响路由、校验、能力或事件转换。

### 3.2 类型专属参数

| 类型候选名 | 用途与配置 | 当前范围 |
|---|---|---|
| `codex` | 本地受管 app-server，配置程序、参数和环境 | 当前优先对接 |
| `codex-remote` | 已有 app-server，配置地址和认证引用 | 连接、身份与恢复行为待验证 |
| `claude` | Claude Code 原生接入 | 准确类型名与接口待确认 |
| `acp` | 标准 ACP 适配，配置符合要求的程序 | 未来扩展 |

候选类型不代表当前可用。未交付类型必须明确拒绝，不能因列入设计而宣告支持。

| 字段候选 | 适用类型与含义 | 必填、默认与约束 |
|---|---|---|
| `config.command` | 本地类型要启动的程序 | 建议显式提供，默认路径待定；必须满足该类型的程序和版本要求 |
| `config.args` | 本地程序参数数组 | 可选，建议空数组；不能覆盖协议必需参数或变成任意 shell 命令 |
| `config.env` | 本地进程环境映射 | 可选，建议空映射；实例级生效，不接收 Session 临时覆盖；继承规则待定 |
| `config.secretRefs` | 本地环境所需密钥引用 | 候选可选字段，形式待定；与普通环境变量同名时建议拒绝 |
| `config.url` | Remote 已有服务地址 | Remote 必填，无默认；只接受已验证的地址方式 |
| `config.authRef` | Remote 连接认证引用 | 服务要求认证时条件必填，字段名和引用形式待定 |

各类型拒绝不属于自身的字段。Remote 不接受本地程序、参数或环境配置，连接服务不意味着能设置远端进程环境。二进制校验、关闭期限、容量和原生数据目录若需配置，归对应类型的明确字段，不增加万能透传参数。

认证只保存引用。使用前解析密钥，查询、日志、错误、历史和证据均不保存其明文。引用失效时明确失败，不改用默认账号或其他凭据。配置快照不保证保留旧密钥。

## 4. 实例状态与健康观察

Runtime 需要表达启动、连接和运行故障。`status` 由系统维护，只用于观察，不是注册输入或 `config`，查询不会启动 Agent。

参考已有 Agent Run 的实例状态设计，建议采用 `status.phase` 和当前 `status.unavailableReason`。它们替代前稿的 `state` 与 `lastError` 默认方案，具体字段与枚举仍待确认。

| phase 候选 | 含义与转换条件 |
|---|---|
| `pending` | 已登记但未激活；允许按使用策略触发激活 |
| `starting` | 正在激活，统一涵盖本地启动、远程连接和握手；成功后 ready，失败后 error |
| `ready` | 具备接收受支持会话操作的条件，不表示每个 Session 健康、前台空闲或一定有实例级进程 |
| `stopping` | 正在结算并释放己方资源；未证实释放时不能报告 stopped |
| `stopped` | 已确认己方运行资源停止，实例配置和 Session 仍存在；允许何种再次激活入口待定 |
| `error` | 激活失败或共享资源不可用；不证明资源释放，也不触发隐式重试 |

Agent Run 已有 pending/starting/ready/error/stopped；本稿另建议 stopping，以区分停止过程与确认释放。启动、连接和握手失败不各占一种 phase，原因另行说明。

| 当前原因的候选字段 | 含义 |
|---|---|
| `status.unavailableReason.reason` | 稳定的 MASS 分类，例如激活失败、连接丢失或共享资源退出，不使用原生错误码 |
| `status.unavailableReason.message` | 脱敏说明，不回显密钥、原始配置或未经处理的上游响应 |
| `status.unavailableReason.stage` | 可选故障阶段，如启动、连接、握手、运行或停止；是否增加待定 |

`unavailableReason` 解释当前不可用或正在恢复的原因，不是历史错误集合。建议 ready 后清空，无当前原因时为空。若需要历史诊断，另行保留，不将它与当前状态混为 `lastError`。独立状态变更时间和已生效配置版本是否对外公开仍待定；普通记录更新时间不能当成状态转换时间。

只有共享运行资源故障才影响实例。单 Session 的参数错误、忙、绑定损坏或自身连接故障不默认使整个实例失败。远程连接丢失只证明观察或控制中断，不证明远端任务结束。

`enabled` 是使用策略，phase 是观察状态，两者独立。持久化过的 ready 不是重启后的存活证据。状态及原因应形成一致观察，旧资源迟到的故障不能覆盖新资源的状态。

实例就绪、可按需激活和服务整体可用是不同判断。Agent Run 将 ready 或可惰性激活的 pending 视为可服务，并允许部分实例失败时服务整体仍可用。MASS 可借鉴这一分层；零实例、已停止实例及健康探针的具体聚合规则待定。整体可用不能替代目标实例和 Session 的状态。

Agent Run 的自动进程恢复不直接成为 MASS 能力。自动重启、重连和恢复策略仍待定；即使启用，也不得重发结果未知的输入、审批或取消操作。

## 5. 生命周期与资源所有权

### 5.1 激活、连接和并发

登记时先校验名称和类型，再由类型验证配置。非法配置不留下可用的半成品。重复名称建议报冲突，更新必须显式进行。

同实例的首次激活、停止、配置变更和打开预留必须协调，避免重复启动或两个并行资源所有者。不同实例可以独立激活。同一 Session 的归档和恢复不能产生两个有效 Attachment。

Attachment 区分打开中、在线、关闭中和已释放。打开失败或失联使其不可用；释放未确认时仍保留关闭未确定状态。Session 的持久记录不随连接消失。

前台工作状态独立于连接。在线不表示空闲，断线不生成工作结束。输入准入、审批、取消和关闭须有明确先后关系；已经交付上游的操作继续按实际结果结算，不能追溯声称未发送。

观察超时不放弃所有权。迟到打开仍由原所有者结算或清理；迟到确认可以更新后续查询状态，但不改写先前返回的未知结果。处理响应和事实不依赖外部调用者在线，也不等待事件处理器完成业务动作。

### 5.2 本地与远程 Codex

本地和远程共用 Codex 协议能力及 MASS 语义，共享命令、事件、审批、取消、错误和恢复规则。区别是资源获取和所有权，不应形成两套协议栈，也不要求共享运行中的连接。

| 行为 | 本地 Codex | Codex Remote |
|---|---|---|
| 激活 | 启动并连接自己拥有的 app-server | 连接已有服务并握手，不启动或重启远端服务 |
| 关闭 Session | 结算并释放目标会话，保留其他会话和服务 | 只处理自己绑定的会话，不干预其他客户端 |
| 停止实例 | 排空已接纳事实，关闭连接并回收己方进程 | 结束自己的连接和本地任务，不停止共享 server |
| 释放证据 | 原生会话释放；必要时己方进程确认退出可证明其资源消失 | 需要远端释放证据，本地连接关闭不能代替 |
| 故障范围 | 共享服务故障影响本实例绑定会话 | 同指一个服务的不同实例可能同时受影响 |

固定官方客户端具备 WebSocket 地址和可选 Bearer token 连接能力，携带 token 时只允许安全 WebSocket 或本机回环 WebSocket。这是只读核实的客户端能力，尚未证明 MASS Remote、远端部署或认证可用；不承诺任意 HTTP、SSH 或其他认证方式。

远程断线不等于取消成功或会话释放。关闭缺少证据时返回未知，保留绑定和诊断，分别表达本地资源已结束与远端结果未确定。

恢复连接不等于恢复 Session。建议先采用显式恢复；不重放业务命令，不把旧 Attachment 的命令转到新连接。相同 URL 不证明相同服务、账号或数据，远程恢复须由适配方验证归属，失败不能新建替代会话。

### 5.3 配置变更与隔离

以下是待确认的简单规则。

| 操作 | 建议行为 |
|---|---|
| 修改 name/type | 拒绝，另注册实例，不改绑原 Session |
| 禁用 | 阻止新建和新恢复；已有在线 Attachment 仍可输入、取消和归档，不隐含强制停止 |
| 有会话引用时修改执行配置或删除实例 | 拒绝，包含离线、归档、打开未结算和关闭未确定的引用 |
| 无引用时修改执行配置 | 校验配置，确认己方运行资源释放后保存新版本，下次使用时激活 |
| 无引用时删除实例 | 确认己方资源回收后删除记录；Remote 不停止外部服务 |

引用检查与会话打开预留必须协调，不能检查后又接入新引用。关闭超时不能丢失资源所有权或立即允许同名替换。

系统必须保留稳定的内部实例身份，并将其与 sessionId 共同用于识别会话归属；不能假设 Agent 的 ID 跨实例或远端服务全局唯一，也不能只用可重建的 name 判断身份。该实例身份不增加用户注册时的顶层 ID 字段。配置版本及非敏感快照的具体形状仍待确认，用于防止最新配置替换原恢复目标。实例身份和配置版本与进程、连接代际分开。是否对外公开及并发更新参数随管理入口确定。

不同进程不自动隔离文件、原生数据、账号凭据、网络或安全沙箱。同用目录或凭据的实例仍可能互相影响。类型必须说明数据位置、共享限制和恢复归属，不由名称或 PID 推断隔离，不自动复制或清理用户目录。远程 Session 工作目录属于远端机器，不能按 MASS 本机目录存在性校验。

## 6. 命令、事件与恢复

### 6.1 结果与能力

统一命令覆盖新建、显式恢复、输入、取消、关闭和实例停止。会话命令绑定具体 Attachment，不能在执行时按名称寻找最新连接。

输入结果区分明确拒绝、已证明接受和结果未知。接受回执仅表达实际观察证据，不等于模型已消费、工作完成或历史已落盘。未知结果不自动重试，外部调用者断开也不撤销已接纳操作。

能力取系统已实现与实际连接支持范围的交集，再受生命周期限制。不支持的输入、工具、配置或交互明确失败，不静默忽略。某类型无法提供相同证据时应表达真实不确定性或不支持，不能降低合同以制造能力一致。

Runtime 使用 MASS 领域错误，区分无效参数、不支持、忙、离线、拒绝及接受、取消、关闭未知。外部协议负责编码，外围不解析原生数字码、方法名、传输或版本字符串来判断行为。

### 6.2 完整事实与提交

统一事实包括用户消息、Agent 消息、思考、工具调用、工具结果及已观察状态。条目完成与前台工作结束分开。工具调用和结果保持公共条目关联，各有独立序号；缺失、空和截断输出分别表达。

适配方提供完整事实或预览。预览只用于实时展示，不累积成历史，也不根据输入副本、空闲、取消、断线或退出补造完整事实。

单一提交核心分配会话内连续序号和时间，写入完整事实及所需恢复证据，刷新后发布同一不可变公共事件给实时订阅和事件处理器。写入失败不发布该记录，并封闭进一步持久写入。持久化屏障不自行承诺掉电不丢或跨所有资源的原子提交。

队列和交付资源有界。慢订阅者不能无限占用资源或阻塞提交核心；事件处理器的业务动作不能阻塞原生控制。停止排空已接纳事实，不宣称尚未接纳的数据、所有后台工作或永久阻塞的存储都已完成。

### 6.3 审批、取消与关闭

原生审批标识、对应关系和决策归适配方管理。审批只作用于原 Attachment 与对应工作，失效或已解决请求不能被迟到决策重新批准。通用层不另建一套原生审批协议。

取消固定目标工作，重复调用可共享同一在途结果。原生确认、实际终止、输入结算和审批结算是不同证据。未知不升格为成功，旧工作未结算时不提前开放新输入。

关闭先限制新输入和审批，再结算目标工作、排空已接纳事实并等待释放证据。确认前保持关闭中，超时返回未知并保留迟到处理和恢复信息，不因此停止健康的共享服务。

### 6.4 不透明信息与恢复

公共会话、事件、能力和错误使用 MASS 语义，不把原生对象改名后当作通用字段。sessionId 使用 Agent 分配的真实 ID，不要求外围理解其格式；ID 的生成权归 Agent 不改变原生协议隔离。适配方保留两类私有信息，恢复绑定和事实证据。外围只无损保存并交回对应类型，不解释原生线程、轮次、状态、传输或版本。认证秘密不属于持久证据。

恢复先校验通用格式、公共身份、序号和配置绑定，再由适配方校验私有绑定、证据与投影一致性。适配验证不要求先启动 Agent。全部已提交记录通过后，才能修未提交尾部、激活并连接 Session。

恢复将已保存的真实 sessionId 交回原实例的适配方，保持该 ID 和历史顺序，产生新 Attachment，不使旧命令改绑。适配方必须确认恢复到原会话，不能用新 ID 冒充恢复成功。不能提供持久会话 ID 的类型必须明确限制相应创建或恢复能力，MASS 不自行造 ID 冒充底层身份。失败不新建替代会话，不补造完成事实，也不以同名实例或最新配置代替原绑定。

终态持久格式区分公共记录与私有证据，发布前保证所需证据已保存，具体形状待定。不支持的旧格式明确报错，不转换或删改原文件；这不取消终态格式自身的冷恢复要求。

## 7. 对外能力与交互契约

本节是 MASS 应用契约草案。操作名、字段和伪代码用来确定职责及语义，不等于已批准的网络方法或序列化格式。外部 HTTP、JSON-RPC 和实时事件承载可沿用当前产品方向，终态映射仍待确认。Codex 原生协议和 ACP 只存在于适配边界内。

### 7.1 调用层次

| 调用层 | 调用者知道什么 | 目标选择 |
|---|---|---|
| 实例管理 | 系统类型和命名配置 | 登记提供 name/type/config；查询、更新或停止选择实例 name |
| MASS 会话入口 | 公共 Session 名称和 Runtime 实例名 | 新建提供 runtimeName；恢复和后续操作从持久会话归属确定实例，不能临时换实例 |
| 已选实例的 Runtime | 当前实例已确定，负责具体运行 | newSession/resumeSession 不再接收 runtimeName，也不接收 name/type/config |
| Attachment 消费者 | 某次具体绑定及其能力 | prompt/cancel/answerInteraction/close 使用原 attachmentRef，不按名称重定位 |
| 观察者 | 实例或会话的公共身份 | 状态、能力、历史与实时订阅分别选择目标，不凭查询隐式激活或恢复 |

外部按 Session 名称提交操作时，MASS 入口在接纳该次操作时固定 Attachment。事件处理器保留的命令也固定原绑定；之后出现同名会话或新连接不能改变目标。

### 7.2 实例管理和查询

以下字段均为应用层概念，类型专属 config 仍由对应适配方校验。

| 操作 | 请求字段 | 前置条件 | 结果及领域错误 |
|---|---|---|---|
| 查询类型 | 无必填字段 | 管理权限范围内可查询，不激活资源 | 已提供类型及配置约束，不把未来类型报为可用 |
| registerRuntime | name、type、config 必填，enabled 候选可选 | 名称未占用，类型已提供，配置有效 | 命名实例及只读 status；重复名称冲突、类型不支持或配置无效 |
| 查询实例/列表 | 单实例查询 name 必填，列表无目标字段 | 不要求 ready | 脱敏配置、能力描述和 status；目标不存在或读取失败 |
| updateRuntime | name、待修改配置必填；期望配置版本为待定条件字段 | 按第 5.3 节引用和停止规则检查 | 新配置版本；冲突、仍被引用、配置无效或资源释放未知，不隐式重启存量会话 |
| deleteRuntime | name 必填 | 建议无持久或临时会话引用 | 仅己方资源释放确认后删除实例；仍被引用或停止未知时保留记录 |
| 查询能力/状态 | 实例 name 或已固定的实例目标 | 读取不激活 | 系统已实现能力、连接已观察能力与生命周期可用性分开；尚未握手的能力保持未确认 |

配置读取不得返回密钥明文。管理入口的权限、网络形式及是否开放在线变更仍待定，表中操作不表示已确定新增网络方法。领域错误统一提供稳定 reason 和脱敏 message；有在途副作用时可附 MASS operationId 与已观察证据，不嵌入原生响应对象或外部协议错误包装。

### 7.3 新建 Session

用户提供唯一 sessionName，底层 Agent 创建并返回真实 sessionId。MASS 不预分配或替换该 ID，用户也不能在创建请求中指定它或伪造恢复绑定。sessionId 对外围是不透明值，不要求符合 Codex thread 的格式。

```text
record CreateSessionRequest
  required sessionName     用户选择的公共会话名称
  required runtimeName     已登记的 Runtime 实例名称
  required cwd             会话工作目录，由目标运行环境解释
  optional sessionOptions  仅限已定义且已支持的 MASS 会话选项

operation MASS.createSession
  request CreateSessionRequest
  result CommittedSession or DomainError

record RuntimeNewSessionRequest
  required cwd             同一会话工作目录
  optional sessionOptions  经过公共校验的 MASS 会话选项

operation SelectedRuntime.newSession
  request RuntimeNewSessionRequest
  result OpenedAttachment or DomainError

record OpenedAttachment
  sessionId                底层 Agent 创建并返回的真实会话 ID，按不透明值保存
  attachmentRef            绑定本次连接的命令与观察目标
  capabilities             此绑定实际支持的能力
  effectiveOptions         实际采用的已定义会话选项
  recoveryBinding          适配方拥有的不透明恢复信息，仅供系统保存
```

SelectedRuntime 已经由 runtimeName 选定，不重复传入实例选择字段。系统同时提供本次操作关联、已固定的实例归属、事实交付、观察期限和迟到结算责任的上下文，不让用户提供事件接收地址、提交序号或原生路由信息。attachmentRef 是有生命周期的系统引用，不是要求客户端传输的内存对象；它与公共 sessionId、私有 recoveryBinding 分开。

cwd 对本地类型表示本机目录，对 Remote 表示远端目录。公共层检查字段形状，适配方检查其运行环境中的有效性，不能将本机存在性校验用于远端。Runtime 实例的程序、环境和认证不由 sessionOptions 覆盖。

模型、工具和权限不是全部类型天然共有的选项。本稿暂不确定它们的最终字段。若提供，应使用已定义的 MASS 模型选择、工具选择或权限配置含义，按能力描述和允许值校验；不得传原生规则对象或通过任意键透传。不支持的键、值或能力明确失败，不忽略，也不悄悄采用其他值。最小创建请求不包含这些选项；连接后发现能力与初步判断不符时，在公开会话前失败并结算新资源。

创建先预留 sessionName 和实例引用，固定稳定实例身份及配置，并建立 MASS operationId 等请求关联；此时尚无 sessionId。newSession 不接收预先指定的底层会话 ID，由适配方请求 Agent 创建会话。Agent 返回真实 sessionId 后，适配方将其随 OpenedAttachment 返回。MASS 原子保存该 ID、用户名称、实例归属和私有绑定，保存成功后才公开成功会话并启用该连接的事件处理器。OpenedAttachment 不等于外部创建成功。

| 创建结果 | 含义及处理 |
|---|---|
| 已提交成功 | 返回 sessionName/sessionId、runtimeName、公共连接状态、实际能力和已定义的生效选项；不返回私有绑定或原生对象 |
| 明确未创建 | 名称冲突、参数无效、能力不支持、实例不可用或上游明确拒绝。未创建资源时释放预留；已打开资源必须先结算和清理 |
| 保存失败 | 不公开成功；清理本次 Attachment，不停止健康共享服务。清理未确定时继续拥有资源和名称预留 |
| 创建结果未知 | 打开或释放超过观察期限，不能断言资源不存在。返回 create_unknown 及 MASS 操作关联，不伪造尚未收到的 sessionId；保留预留，收到迟到 ID 后继续结算或清理其资源，禁止自动再次创建 |

系统在有副作用前分配 operationId，关联公开响应、迟到结算和诊断，不使用原生请求标识。外部承载的 requestId 只关联一次请求，不提供幂等保证。首版不承诺客户端幂等键或自动重试；operationId 是否提供独立查询、保存期限及跨重启语义仍待定。未知期间同一名称不能再次创建，不能用新请求覆盖原打开的所有权。

### 7.4 恢复 Session

| 调用 | 请求字段 | 前置条件与结果 |
|---|---|---|
| MASS.resumeSession | sessionName 必填 | Session 存在且不在线、不在关闭未确定或其他打开结算中。由持久记录选择实例，不允许请求覆盖 runtimeName |
| SelectedRuntime.resumeSession | 已保存的真实 sessionId、持久 cwd、有效选项和不透明 recoveryBinding 必填；系统提供已验证的稳定实例归属及本次恢复上下文 | 已完成通用验证和适配方的本地证据验证，实例按策略可使用；成功返回具有同一 sessionId 的新 OpenedAttachment，不创建替代会话 |

完整历史和私有证据由系统按恢复合同交给适配方验证，不作为用户请求字段。恢复完成后返回同一 sessionId 和新连接状态，不重放历史给事件处理器。

领域错误包括不存在、已在线、关闭未确定、配置绑定不匹配、证据损坏、实例不可用、不支持恢复、明确恢复拒绝和 resume_unknown。已产生资源后的失败继续按原所有权结算，不 fallback 到新建。Remote 还须验证服务与账号归属。

### 7.5 Attachment 命令

下表描述已固定 Attachment 的操作。外部入口另用 sessionName 选择现有绑定，不把 attachmentRef 或原生标识直接暴露为必需请求字段。

| 操作 | 请求字段 | 前置条件 | 结果与主要领域错误 |
|---|---|---|---|
| prompt | content 必填，非空且有界的 MASS 内容块；当前最小能力只接受文本 | 在线、支持输入、非关闭中且输入准入允许 | SubmissionReceipt；内容无效、不支持、busy、取消结算中、离线、明确拒绝、acceptance_unknown |
| cancel | 无必填业务字段，目标由原绑定捕获 | 支持取消；原绑定可观察或具有可结算操作 | 已确认控制或本地无工作结果；不等于前台终止。离线、不支持、cancel_unknown；领域名称不采用原生方法名 |
| answerInteraction | requestRef、answer 必填，均为 MASS 定义的交互引用和答案 | 该绑定确有未解决请求，声明支持其种类，答案符合该请求定义 | 答案处理回执；不支持、请求失效、目标不匹配、重复回答冲突、明确拒绝或结果未知 |
| closeAttachment | 无必填业务字段；使用系统规定的关闭期限 | 目标是原 Attachment，关闭开始后禁止新输入和新审批决策 | 释放已确认或 close_unknown；不删除公共 Session，不停止健康共享实例 |

SubmissionReceipt 至少关联系统生成的 submissionId，并表达已观察到的接受证据；只有实际完整用户条目可关联时才提供公共 userItemId。回执不声称历史已提交或模型已消费，具体证据枚举待定。掉失观察者不得变成成功回执。

requestRef 不是原生审批 ID。交互种类和 answer 结构只有在其 MASS 语义与能力正式定义后才可用，不能使用原生任意对象。当前 Codex 自动审批由适配方维护，不因此宣称已支持外部人工回答接口。不支持 answerInteraction 时应明确失败；迟到回答不能授权新连接或新的工作。

### 7.6 观察、订阅和关闭范围

| 操作及所属层 | 请求字段 | 结果、条件及错误 |
|---|---|---|
| 查询 Session 状态，MASS 入口 | sessionName 必填 | 持久身份、连接状态、前台观察及实际能力；离线可查，不自动恢复，不把未知状态填成空闲 |
| 查询 Attachment，具体绑定 | 无目标选择字段 | 原绑定状态与能力，不能看到同名替代绑定的状态 |
| 查询历史，MASS 入口 | sessionName 必填，分页参数可选 | 已提交公共记录；不存在、参数无效或历史损坏明确失败，不激活 Runtime |
| subscribeEvents，MASS 观察入口 | sessionName 必填，事件筛选是否提供待定 | 建议只订阅此后事件，无初始历史、自动恢复或跨连接恰好一次保证；离线或不支持时失败，慢订阅者按有界策略断开 |
| 事实交付，Runtime 到提交核心 | 系统固定会话与 Attachment 上下文；消息、工具或状态事实 | 适配方提供归一化事实，提交核心分配公共 seq/time；不是用户订阅原生协议 |
| archiveSession，MASS 会话入口 | sessionName 必填 | 编排关闭当前 Attachment，释放确认后返回离线；保留身份和历史，未知时保持关闭中 |
| stopRuntime，实例管理 | 外部选择实例 name；已选 Runtime 不重复接收名称 | 停止接纳新工作，结算和排空已接纳部分，按所有权回收资源；返回停止结果或 stop_unknown，不删除配置和 Session |

订阅取消只停止观察，不取消 Agent 工作。归档不等于删除会话；本稿不增加销毁会话历史的操作。Remote 的本地连接可停止，但远端会话释放仍可能未知，应分别报告，不能仅以 phase=stopped 声称远端工作结束。

### 7.7 创建会话的完整例子

以下仅展示应用交互，省略已登记实例 config 中的程序细节，不代表最终 wire。

```text
record RegisteredRuntime
  name = codex1
  type = codex                 候选类型名
  config = 有效的本地运行配置
  status.phase = pending      候选状态名

record CreateSessionRequest
  sessionName = task-a
  runtimeName = codex1
  cwd = /work/project-a

record PendingCreation
  sessionName = task-a       MASS 预留的用户名称
  operationId = O1           MASS 分配的本次操作关联
  runtimeBinding = R1        已固定的稳定实例归属，不是另一个会话 ID

operation codex1.newSession
  request
    cwd = /work/project-a
  context
    operationId = O1
    runtimeBinding = R1
  result
    sessionId = S1           Agent 创建并返回的真实 ID，不解析其格式
    attachmentRef = A1
    capabilities = 实际支持的会话能力
    recoveryBinding = B1      仅系统持久化，不交给客户端

record CommittedSession
  sessionName = task-a
  sessionId = S1
  runtimeName = codex1
  connectionState = online
  capabilities = 实际支持的会话能力
```

MASS 接到请求后预留 task-a 和实例 R1，分配操作关联 O1，不分配 sessionId。codex1 尚未激活，于是启动自己的服务，再请求 Agent 创建会话。Agent 返回真实 ID S1，适配方连同 A1 和 B1 交回。MASS 保存 S1、task-a、R1 和 B1，保存成功后启用事件处理器并返回 CommittedSession，创建过程不偷偷发送 prompt。runtimeBinding 在示例中只表示系统内部的持久归属，不是已经确定的公开字段。

第二个 Session 若也选 codex1，使用同一服务但获得不同绑定。若选 codex2，则在它首次使用时启动独立服务。Remote 的同一交互由所选实例连接已有服务，cwd 按远端环境解释；外部仍使用相同的创建字段。

若 A1 已打开但保存失败，MASS 不返回成功，并仅清理 A1。释放未知则保留名称和资源所有权，返回未知结果及关联，不再创建第二个 task-a。客户端失去响应也不能直接重试创建；后续确认方式随操作查询合同定稿。

## 8. Claude Code 与 ACP

Claude Code 原生类型遵守同一 Runtime 合同，但不模拟 Codex 的原生对象或进程拓扑。其消息、审批、接受证据、资源与恢复由对应适配方负责。WAP 的实际接口尚未核实，不据此确定启动参数或宣称官方支持。

ACP 使用官方标准及真实协商能力。用户配置符合要求的程序，不提供 MASS 的新实现。底层 Agent 产品不驱动通用层的原生分支。未来类型不需要复制 Session 管理、提交核心或增加动态插件机制。

## 9. 待定事项

1. 类型准确名称、Claude 原生接口及是否保留无行为的 Agent 描述字段。
2. 注册管理采用在线入口还是配置文件，唯一配置事实源、权限与并发更新规则。
3. 各类型参数、默认程序、版本校验、环境与密钥引用、数据目录和账号隔离。
4. 启禁和配置变更规则，配置快照与生效版本如何表达。
5. 状态枚举、当前原因及可选故障阶段、状态变更时间、健康聚合；自动重启和重连策略。
6. Remote 地址、认证、远端身份、释放证据及真实恢复能力；公共结果、事件和持久格式的最终字段。
7. 本节操作的外部承载映射、创建与恢复的操作关联查询、会话选项、交互回答 schema，以及事件订阅和分页字段。

## 10. 行为验收标准

- 以 name/type/config 注册，Session 用 runtimeName 引用。登记和离线查询不启动 Agent，未知类型、重复名称、非法配置和不支持能力明确失败。
- 本地实例首次使用后独立拥有服务，同实例多 Session 正确共享，不跨实例去重；重启不改变实例归属。
- 状态只读且与实际资源一致，启动和连接故障可诊断，单 Session 错误不误伤实例。整体可用不掩盖某实例不可用，远程失联不伪装为任务终止。
- 本地与 Remote 使用相同业务合同，Remote 停止不关闭共享服务，也不按本机路径判断远端目录。
- 旧 Attachment 命令不影响新连接；接受、审批、取消、关闭及未知结果保留真实对应和隔离。
- 外围能处理不含 Codex 原生坐标的事实与绑定，不依赖 SDK 类型或原生字段决定行为。
- 完整事实及恢复证据先持久化后发布，预览不成为历史，工具关联和输出完整性保持准确。
- 终态会话冷恢复保持公共身份与顺序；损坏在修尾和激活前失败，不新建替代会话。配置、同名重建、账号或数据位置变化不静默改换恢复目标。
- 外部创建按 runtimeName 选实例，实例内新建不重复选择；sessionId 由 Agent 创建并返回，newSession 不接收预设 ID；sessionName 和操作关联先行预留。会话按稳定实例归属与不透明 sessionId 识别，恢复使用同一真实 ID，不以同名实例或伪造 ID 替代。Attachment 与私有绑定不冒充已提交会话；保存失败或结果未知不会重复打开或丢失迟到资源所有权。
