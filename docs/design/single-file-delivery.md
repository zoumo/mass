# 单可执行文件交付合同

当前交付是 MASS 的一个原生可执行文件，不增加安装器、自解压运行方式或另一条产品路径。该合同描述部署结果，不规定构建语言。构建选项、依赖锁定、链接检查和既有验收步骤见[发布实现指南](../develop/release-implementation.md)及[构建运行指南](../single-file-delivery.md)。

## 运行环境

支持本机 macOS arm64，声明的最低部署环境为 macOS 14.0。Linux、其他架构和交叉编译未验收，不声称可用。声明的最低系统版本与实际测试系统版本分别记录。

部署只需要 MASS 可执行文件，不依赖源代码、构建缓存、包管理器或额外语言运行环境。允许操作系统提供的动态库与系统框架，不允许未随合同声明的第三方动态库或机器专属加载路径。macOS 交付不宣称完全静态。

配置、可写数据目录、认证以及明确配置的外部 Codex 程序和所需资源是独立部署输入。MASS 单文件不包含用户凭据，也不消除外部 Agent 的系统和网络要求。离线查询不要求 Codex 可执行或在线。

## 产物与验收

发布附带来源及校验清单，用于绑定源码、依赖、构建环境、产物摘要和链接检查；清单不是产品运行输入。输入锁定和可重复步骤不等于不同环境下的字节级可复现承诺。

验收须将产物单独复制到隔离目录，验证帮助、启动、健康、真实会话、历史一致性、停止、离线读取、显式冷恢复与己方进程清理。历史和 SSE 的一致性不能由输入回执替代；外部 Agent 后台活动也不能由 MASS 退出推断已全部停止。
