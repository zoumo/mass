# MASS v2 会话服务

本词汇表描述本次从零构建的新 Rust 项目的领域术语；不沿用旧设计中“v2”名称所指的对象模型。

## Language

**实时事件流**：会话运行时向当前订阅者发送的变化通知，其中的内容增量用于展示正在生成的输出。它不承担历史查询或补发过去增量的职责。
_Avoid_: 将实时事件流称为完整会话历史

**会话历史**：为以后查询而保留的已提交会话记录，不包含每个 chunk 或 delta 的逐帧记录。
_Avoid_: 将历史查询称为实时流重放

**会话条目**：会话中具有独立身份、可以持续更新的一份消息、思考、工具调用或计划。增量内容和完整内容属于同一个条目。
_Avoid_: 将同一条目的每次更新视为不同条目

**条目完成**：某一条消息或思考结束生成、可以确定其完整内容的边界。它可以早于前台工作的结束。
_Avoid_: 将条目完成等同于整个前台工作结束

**事件处理器（EventHandler）**：消费统一事件，并据此更新自身负责的状态或触发动作的处理逻辑。
_Avoid_: 将事件处理器等同于底层协议解析器

**前台工作状态**：Agent 当前前台工作正在进行、被用户操作阻塞或已经结束的状态。它不与单次用户输入一一对应，也不表示后台活动是否全部结束；有待回答请求不一定意味着前台被阻塞。
_Avoid_: 将前台空闲等同于所有工具完成

**会话元信息**：描述会话的标题、配置选项、可用命令和用量等当前信息，用于初始化和更新客户端界面，不等同于会话内容或前台工作状态。
_Avoid_: 将所有会话信息统称为运行状态

**可用能力**：客户端当前可以使用的服务功能范围，同时受到服务本身与所连接 Agent 的支持范围约束。
_Avoid_: 将 Agent 宣告的全部能力当作服务已支持的全部能力
