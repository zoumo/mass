# principles 内容边界

本目录只维护可跨项目复用的工作、编码、测试与验收原则，以及按语言分类的开发规范。原则可以规定如何开发和验证，但不得依赖当前项目的目录布局、组件名称或实现状态。可跨项目复用的语言级配置模板可以随规范放在对应语言的 templates/ 下，由相关规范提供入口；项目实际使用的配置仍由实现目录维护。

以下内容放在仓库根目录或对应语言实现目录的 AGENTS.md、README 等操作说明中，不写入本目录：

- 当前项目的源码路径、二进制名称和构建产物位置。
- 构建、格式化、lint、测试与验收的具体命令、脚本和环境变量。
- 当前使用的工具版本、配置样例、运行数据位置和迁移注意事项。
- 当前实现的支持范围、进度、缺口和验收结果。

当前项目的读取顺序、知识目录写入授权和工作流程归入仓库或知识目录的 AGENTS.md，不在本目录单独维护工作流程文档。当前项目的架构、模块职责、领域模型和 API 合同归入知识目录对应的设计与合同页面，不写入原则正文。原则中的导航链接和来源说明可以指向项目资料，但不在此重复维护项目事实。

新增或修改内容时，先判断该规则在更换项目名称、源码目录或构建工具后是否仍然成立。若不成立，应移到项目操作说明或设计合同页面。目录索引只维护原则导航，不承担项目操作手册。

本目录仍遵守上级 [harness 写入规则](../AGENTS.md)；本文件不增加写入授权。
