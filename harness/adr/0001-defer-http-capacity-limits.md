# 暂不强制限制 HTTP 请求体大小等容量边界

2026-10-20 决定：当前阶段不对 HTTP 请求体大小等容量边界设置强制限制，不预设容量阈值、增加相应限制配置或要求超限拒绝验收。暂不为假设场景引入限制策略；遇到具体问题时，再根据实际请求、部署条件与影响讨论是否限制、限制范围及阈值。[^direction]

该决定适用于 [HTTP 承载合同](../bindings/http.md)。字段格式、业务合法性、认证，以及既定 SSE 流交付与有界缓冲语义继续按各自合同执行；本决定不承诺底层 HTTP 库、代理或运行环境具备无限容量。已有错误分类仅描述实际发生的失败，不作为引入 HTTP 限额的要求。

后续调整须以具体问题为依据，明确决策与验收范围，并同步更新本 ADR 和 HTTP 合同。

[^direction]: 本次讨论中，负责人要求“不限制”，并要求将暂缓 HTTP 请求体大小等边界限制的决定记录为 ADR。
