# harness 写入入口

本目录是指导项目演进和发展的唯一真相源，按 OKF v0.2 管理。内容入口见 [index.md](index.md)，工作规则见 [principles/agent-workflow.md](principles/agent-workflow.md)。

写入本目录之前，必须有覆盖当前修改范围的人类明确请求或事先同意；否则仅可读取，并在目录外准备建议或草案后征询同意。规则覆盖新增、编辑、移动、重命名、删除、格式化、生成产物及其他工具写入。已获得的授权在其范围内继续有效，不重复请求；新增范围须另行获得授权。

完整约定见 [harness 写入授权](principles/agent-workflow.md#harness-写入授权)。
