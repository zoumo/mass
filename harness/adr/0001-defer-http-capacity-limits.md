# 暂不预设业务消息容量限制

当前阶段不对业务消息大小等容量边界预设强制限制，不预设容量阈值、增加相应限制配置或要求超限拒绝验收。暂不为假设场景引入限制策略；遇到具体问题时，再根据实际请求、部署条件与影响讨论是否限制、限制范围及阈值。[^direction]

该决定适用于 [JSON-RPC 编码](../bindings/jsonrpc.md#基础规则) 与 [WebSocket 绑定](../bindings/websocket.md)。字段格式、业务合法性、认证、订阅有界缓冲和写入期限仍按对应合同执行；不保证底层库、代理或运行环境具有无限容量。

更换传输不能悄悄启用未经确认的消息大小限额，也不能把本决定解释为允许无限事件队列。后续调整依据实际问题明确范围、阈值和验收，再同步合同。

[^direction]: 本次讨论中，负责人要求“不限制”，并要求将暂缓 HTTP 请求体大小等边界限制的决定记录为 ADR。
